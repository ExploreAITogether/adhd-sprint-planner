Why I built it

I have ADHD. The hardest part of my day is not doing the work. It is the ten minutes before, when everything I need to do is a tangled cloud and I cannot pick a thread. Every planner I tried wanted me to already know my tasks, sort them into projects, and set due dates. By then I had closed the app.

So I made the opposite. One text box. Type or talk into it like you would to a friend. The AI pulls out the real tasks, caps them at five so the list never becomes a wall, and gets out of the way. Finishing one feels good on purpose.

How it works

🧠
1. Dump

Type or hit the mic and ramble. Half sentences are fine. "Email Sarah, the thing with the car, groceries maybe, finish the deck" all works.

✨
2. Sort

Gemini turns it into one to five clear tasks, each with an emoji and tags. Never more than five. Drag to reorder if it guessed the priority wrong.

🎉
3. Finish

Check tasks off with a chime and a burst of confetti. Stuck on one? "Help Me" writes a prompt you can paste into Claude or ChatGPT.

Also in the box

  • Weekly themes. Give each weekday an emoji and a focus, like "📝 Writing Wednesday". It shows above the box so you start in the right headspace.
  • History you can search. Every sprint is saved. Filter by tag, search by word, export to Markdown.
  • Calm by design. Soft gradients, light and dark modes, gentle animations. Sounds can be switched off.
  • Hotkey friendly. Launch it again and it brings the open window forward instead of opening a second copy. Works nicely on a Stream Deck button.

First launch: three steps

It takes about three minutes. The only setup is a free AI key, which you keep. I never see it.

Step 1 · Install and open it

The app is not signed with an Apple or Microsoft certificate yet, because that costs more per year than this free tool earns. So your computer will warn you once. Here is what to click.

Mac: open the .dmg and drag the app to Applications. Double-click it. macOS will say it cannot verify the developer. Click Done, then open System Settings → Privacy & Security, scroll down, and click Open Anyway. You only do this once.

Windows: run the -setup.exe. If a blue SmartScreen box appears, click More info, then Run anyway.

Step 2 · Get a free Gemini key

The AI parsing runs on Google's Gemini. Google gives everyone a free key with a generous daily allowance, far more than a planner needs.

  1. Go to aistudio.google.com/apikey and sign in with any Google account.
  2. Click Create API key.
  3. Copy the key. It starts with AIza.

Step 3 · Paste it into Settings

The app shows a small "Add key" notice on first launch. Click it, or the gear icon in the top right, paste your key into Gemini API key, and hit Save. That is it. Start dumping.

Privacy, in plain words

Everything you type is stored in a single database file on your own computer. There is no account, no sign-up, no telemetry, and no server of mine anywhere in the chain.

The one thing that leaves your machine is the text of your brain dump, and a task title when you ask for a "Help Me" prompt. That goes straight from your computer to Google's Gemini API, using your own key and under Google's terms. If you ever want to stop, clear the key in Settings and the app goes fully offline. Your history still works.

Quick answers

Is it really free? What's the catch?

Really free, no catch. There is no paid tier, no trial, and no upsell inside the app. The code is open source under the MIT license, so you can read every line. The only cost to you is a Google account for the free Gemini key.

Why do I need my own API key?

Because the alternative is me baking my key into the app, which means every download shares one quota and one bad actor can drain it for everyone. Your own key means your usage is yours, nothing routes through me, and the tool stays free forever instead of until my bill gets scary.

It says "Gemini rejected the API key." Now what?

Open Settings, click the eye icon to reveal the key, and check for a missing character at either end. If it looks right, make a fresh key in AI Studio and paste that instead. Keys from other services, like OpenAI or Anthropic, will not work here.

It says "Slow down! Take a breath." Is it broken?

No. That is Google's free-tier rate limit. Wait a minute and try again. It almost never happens in normal use.

Does it work offline?

Your history, settings, and existing sprints all work offline. Turning a new brain dump into tasks needs an internet connection, because that part is the AI.

Is there a phone version or sync?

Not yet. It is desktop only and local only, on purpose. If enough people ask, optional sync is on the ideas list.

How do I update it?

Download the newest installer from the same GitHub link and install over the top. Your data and settings stay put. There is no auto-updater yet.

Something's broken. Where do I tell you?

Open an issue on GitHub or use the Support page. Tell me your operating system and what you clicked right before it went wrong.
