# Website page drafts

Copy-paste HTML for the exploreaitogether.com pages that present this tool.
Each file goes into one WordPress "Custom HTML" block on a full-width,
no-sidebar page template. All styles are inline.

| File | Suggested URL |
|------|---------------|
| `free-tools-page.html` | `/tools/` (parent page, nav label "Free Tools") |
| `adhd-sprint-planner-page.html` | `/tools/adhd-sprint-planner/` (child page) |

Placeholders to fill before publishing are listed in the comment at the top
of each file (screenshots, the transcript tool's details, the blog post URL).
The GitHub download links only resolve once the repository is public and a
bring-your-own-key release has been published.
